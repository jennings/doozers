Your SSH keys let your agents' workspaces use ssh and git over SSH as you. A workspace can ask Doozers to sign with a key but can never read it. Doozers keeps each private key encrypted and never shows it again, so register the public key wherever it should be accepted, such as your GitHub account.

Generate a key

RSA keys take a few seconds to generate. They sign with SHA-2, which GitHub and current servers accept.

Upload a key

Paste the key, or choose its file below. Doozers reads OpenSSH, PKCS#1 RSA, SEC1 EC, and PKCS#8 keys in PEM form. PuTTY (.ppk), DSA, and security keys (sk-) aren't supported.

Doozers decrypts the key with it once and stores the key without the passphrase, because nobody is there to type it later.
